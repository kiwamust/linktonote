# LinkToNote for Obsidian

**LinkToNote for Obsidian**は、大量のWebリンクを効率的にObsidianに取り込むためのStreamlitアプリケーションです。複数のリンクを一括処理し、Obsidian形式のMarkdownファイルを生成します。

## 🌟 主な特徴

- **大量リンクの高速処理**: 複数のWebリンクを一括で処理
- **Obsidian完全対応**: フロントマター、タグ、適切なファイル名
- **堅牢なエラーハンドリング**: ネットワークエラーやタイムアウトに対応
- **プログレスバー**: 処理状況をリアルタイムで表示
- **重複除去**: 重複するリンクを自動的に除去
- **URL検証**: 無効なURLを事前にチェック
- **タグ管理**: デフォルトタグと個別タグの設定
- **一括ダウンロード**: ZIP形式での一括ダウンロード

## 🚀 新機能・改善点

### Obsidian連携強化
- **フロントマター対応**: タイトル、URL、作成日時、タグを自動追加
- **最適化されたファイル名**: 日付プレフィックス + クリーンなタイトル + ドメイン
- **バックリンク用タグ**: Obsidianでの検索・整理に最適

### パフォーマンス改善
- **エラーハンドリング強化**: より詳細なエラーメッセージとフォールバック
- **プログレスバー**: 処理状況の可視化
- **レート制限対策**: サーバー負荷を考慮した処理間隔

### UI/UX改善
- **大型テキストエリア**: 大量リンクの入力に最適化
- **コンパクトなプレビュー**: エキスパンダーによる効率的な表示
- **サイドバー設定**: 各種オプションの集約

## 📦 インストール

1. **リポジトリのクローン**
   ```bash
   git clone https://github.com/yourusername/linktonote.git
   cd LinktoNote
   ```

2. **依存ライブラリのインストール**
   ```bash
   pip install -r requirements.txt
   ```

3. **アプリの起動**
   ```bash
   # 基本版（従来版）
   streamlit run linktonote.py
   
   # 改善版（推奨）
   streamlit run linktonote_improved.py
   ```

4. **ブラウザでアクセス**
   Streamlitが起動し、ブラウザに自動的に表示されます。手動で開く場合は、`http://localhost:8501`にアクセスしてください。

## 💡 使い方

### 1. 基本的な使用手順

1. **設定調整（サイドバー）**
   - デフォルトタグの設定
   - フロントマター追加の有無
   - その他オプション

2. **リンク入力**
   - 改行区切りで複数のWebリンクをテキストエリアに入力
   - 重複除去・URL検証オプションを選択

3. **一括処理**
   - 「🚀 一括処理開始」ボタンをクリック
   - プログレスバーで進捗確認

4. **メモ・タグ追加**
   - 各リンクに個別のメモを追加
   - 追加タグの設定（必要に応じて）

5. **ダウンロード**
   - 個別ファイルまたはZIP形式での一括ダウンロード

### 2. Obsidianでの使用

1. 生成されたMarkdownファイルをObsidianのvaultフォルダにコピー
2. フロントマターがObsidianのプロパティとして認識される
3. タグでの検索・フィルタリングが可能
4. バックリンクでの関連ページ発見

## 📋 生成されるMarkdownファイルの例

```markdown
---
title: "Example Article Title"
url: https://example.com/article
created: 2024-01-15 14:30
tags: ["webclip", "linktonote", "research"]
---

# Example Article Title

**URL**: [https://example.com/article](https://example.com/article)

**説明**: This is an example article description...

## メモ
研究に関する重要な記事。後で詳しく読む。

#webclip #linktonote #research
```

## ⚙️ 設定オプション

| 設定項目 | 説明 | デフォルト値 |
|---------|------|-------------|
| デフォルトタグ | すべてのファイルに自動追加されるタグ | `webclip, linktonote` |
| フロントマター追加 | Obsidianのメタデータを追加するか | `有効` |
| 重複リンク除去 | 重複するURLを自動除去 | `有効` |
| URL妥当性チェック | 無効なURLを事前にチェック | `有効` |

## 🔧 技術仕様

- **言語**: Python 3.7+
- **フレームワーク**: Streamlit
- **主要ライブラリ**: 
  - requests (HTTP通信)
  - BeautifulSoup4 (HTML解析)
  - markdownify (HTML→Markdown変換)
- **対応メタデータ**: Open Graph, Twitter Cards, 標準HTML
- **ファイル形式**: Markdown (.md), ZIP

## 🐛 トラブルシューティング

### よくある問題と解決方法

1. **プレビュー取得エラー**
   - ネットワーク接続を確認
   - URLが正しいかチェック
   - アクセス制限のあるサイトは取得不可

2. **処理が遅い**
   - レート制限対策として0.1秒の待機時間を設定
   - 大量リンク（100個以上）は小分けして処理推奨

3. **文字化け**
   - UTF-8エンコーディングで保存
   - Obsidianの文字エンコード設定を確認

## 📈 パフォーマンス

- **処理速度**: 約1-2秒/リンク（ネットワーク状況による）
- **推奨リンク数**: 一度に50-100個まで
- **メモリ使用量**: 軽量（大量処理時でも数十MB）
